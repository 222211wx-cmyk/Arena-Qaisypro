# Arena Qaisypro

## حق المواطن

المواطن يسجل حساباً واحداً ويستعمله في أقسام المنصة على **نفس النطاق**، مع جلسة آمنة HttpOnly وتجديد نافذة الخمول لمدة 30 يوماً عند النشاط. لا تعني «يبقى مفتوحاً» إلغاء انتهاء الجلسات أو الحماية أو تسجيل الخروج أو إلغاء الجلسة بعد استرجاع الحساب. لا تنسخ رموز الدخول إلى localStorage أو BroadcastChannel. فتح نطاق Replit ونطاق Vercel لا يشارك Cookie تلقائياً؛ يحتاج موفّر هوية موحّد إن أردت SSO بين نطاقين مختلفين.

أداة 🌐 الترجمة + ✎ تعمل على الواجهة نفسها دون استبدال النماذج أو قيم الحقول. تستعمل القواميس الموجودة، وتتيح العربية والدارجة والفرنسية والإنجليزية والإسبانية وتغطية أمازيغية محدودة (ⴰⵣⵓⵍ / Azul). النص غير المغطى يبقى أصلياً؛ لا يوجد ادعاء ترجمة شاملة لكل لغة. التصحيح يُحفظ على الجهاز محلياً لكل لغة ونص، وليس في بيانات المواطن أو قاعدة البيانات.

## الوصول والاسترجاع

- الدخول يقبل البريد الإلكتروني أو اسم اللاعب دون حساسية لحالة الحروف، مع التحقق من كلمة المرور في الخادم.
- ترسل الواجهة إشارات تحديث جلسة فقط للتابات الأخرى؛ كل تاب يعيد التحقق عبر `/api/auth/me`. لا تُعتبر بيانات التخزين المحلي هوية موثّقة.
- `/forgot-password` يوجّه لاسترجاع كلمة السر عبر Firebase SMS للهاتف الموثق مسبقاً. الاسم/البريد وتاريخ الميلاد ليسا إثبات ملكية، ولا تُكشف مطابقة معلومات حساب للزوار. لا يصلح إدخال أي هاتف جديد لاستعادة حساب شخص آخر.
- إذا لم يوثّق المواطن هاتفاً قبل فقدان كلمة السر، يحتاج قناة استرجاع موثوقة/موفّر بريد مهيأ أو تدخلاً إدارياً موثقاً؛ لا يُرسل رمز وهمي. لا توجد إضافة Twilio أو مزوّد Email في هذا التغيير. لا يُعاد استعمال `email_verification_codes` كرمز SMS ولا يُحذف الجدول.
- لا يوضع البريد الشخصي للمشتكي في commit عام. تفاصيل الشكاية تبقى خارج تاريخ المستودع العام.

## الكليبسز والبيانات

رسالة عدم رجوع كليبسز عامة لا تثبت خلو قاعدة البيانات. تحقق من `/api/clips/feed` وحالة الفلاتر/التجميد ومالك الكليب ومراجع R2. لا تزرع سجلات من عدد مفترض أو من أسماء ملفات R2 وحدها؛ تحتاج ملكية وبيانات metadata صحيحة ومراجعة قبل أي استيراد.

Production يعيد استعمال أسرار المشروع الحالية دون نسخ أو تغيير. لا يمكن إثبات تطابق قاعدة Replit من إعدادات Vercel وحدها. لا يُحذف `email_verification_codes` ولا تُجرى migrations أو seed عند إقلاع الاستضافة.
